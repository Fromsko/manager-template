# AGENTS.md

**Tech Stack**: React 19 + Rsbuild + Ant Design 6 + TailwindCSS V4 + TypeScript

**Key Principles**: Maintainable, performant, accessible code following React best practices.

## Commands

- `bun run dev` - Start dev server (http://localhost:3000)
- `bun run build` - Production build
- `bun run preview` - Preview production build

## Styling

- **Ant Design**: Component library for UI
- **TailwindCSS V4**: Utility-first CSS with @layer directive for Ant Design compatibility
- **CSS Layering**: Ant Design styles load before Tailwind utilities (configured in App.css)
